# Aetherion.io — Landing Page

> AI That Serves Humanity, Nature & Life

A warm, premium landing page for the Aetherion ethical AI platform, built with pure HTML + CSS + vanilla JS. No frameworks, no dependencies.

## Stack

- HTML5 · CSS3 · Vanilla JS
- Google Fonts: Orbitron + Inter
- GitHub Pages deployment

## Features

- Canvas particle system (warm amber tones)
- Scroll-triggered reveal animations
- Animated stat counters
- Mobile-first responsive layout
- Warm glow effects throughout

## Local Development

```bash
# Serve locally with any static server, e.g.:
npx serve .
# or
python -m http.server 8080
```

Then open `http://localhost:8080`.
